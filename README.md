# chaddytwiceover — personal lab site

Personal hobby site built with **Next.js App Router + TypeScript + Tailwind CSS**.

This repo is a digital home for experiments, notes, and links — not client work and not a business site.

## Core sections

- **Home**: intro, featured experiments, and recent notes
- **Lab**: project playground with status, tech notes, and demo/detail paths
- **Whatever**: lightweight posts/notes stream
- **Socials**: social hub with room for new platforms
- **Guestbook**: simple “say hi” contact entry point

## Run locally

```bash
npm install
npm run dev
```
